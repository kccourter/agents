# Global Agent Instructions — Example

Adapt deliberately before installing. This example is not an instruction to
replace an existing global file or activate a project workflow globally.
Keep project ownership, runtime rules, and remote policy in local instructions.

- Work toward the user's accepted outcome and preserve existing authorization.
- Match process to scope: a local fix needs focused inspection, implementation,
  verification, and a receipt; a cohesive feature needs one contract; coordinated
  changes retain real producer/consumer gates.
- Choose implementation tactics and bounded investigation within approved
  invariants, ownership, dependencies, and resources. Ask only when those
  boundaries or external authority need a new decision.
- Prefer suitable existing code and simple maintainable solutions. Add useful
  regression coverage for existing defects as well as changed behavior.
- Preserve unrelated work. Validate the actual change and report limitations.
- Follow the adopted project's commit and remote-action policy. Do not add
  repeated approval for actions already authorized.
