# Records

Use this index only when it helps navigate multiple receipts. Link each useful
record with its outcome/status and evidence. Keep current goal status in the
goal index instead of maintaining another ledger here.

A receipt captures changes/decisions, commands/results and relevant source/input/
environment identities, limitations, commit/worktree state, and any next action.
A record of an open investigation remains explicitly open. Link reusable
findings from the current reference or goal index with applicability and
supersession information.
