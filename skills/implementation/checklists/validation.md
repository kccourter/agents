# Validation Checklist

Select checks for the behavior and risk, plus every check required by the
accepted task and applicable repository instructions.

- [ ] Focused behavior/regression checks exercise observable outcomes and meaningful failure modes.
- [ ] Required integration, formatting, lint, type, or other repository checks pass.
- [ ] Evidence identifies commands/results and relevant source, environment, input, and fixture identities.
- [ ] Manual verification, if needed, records setup, action, and expected result.
- [ ] Changed code or unresolved concerns have not invalidated reused evidence.
- [ ] Failures, unexecuted checks, and limits are explicit in the existing receipt.

A recorded blocker does not satisfy a required check. Fix failures within the
approved outcome; request a decision only when progress needs authority beyond
it. Do not repeat passed checks unless new changes, failures, or unresolved
concerns justify it. A reversible documentation edit may need only focused
consistency checks and diff review.
